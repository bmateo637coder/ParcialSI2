================================================================================
DIAGRAMAS DE ESTADO Y DE NAVEGACION - UML 2.5
FashionStore
================================================================================

4 diagramas de estado y 4 de navegacion, todos en horizontal (izq -> der).
Pegar en draw.io con: Arrange > Insert > Advanced > PlantUML.

Estados tomados del codigo:
  ProductProposal : PENDIENTE, APROBADA, RECHAZADA
  Product         : ACTIVO, INACTIVO
  Order           : PENDIENTE, PAGADO, ENVIADO, ENTREGADO, CANCELADO
  Payment         : PENDIENTE, COMPLETADO, FALLIDO

La navegacion se dibuja como diagrama de componentes: cada pantalla es un
componente y las flechas son los enlaces a los que se puede ir.


================================================================================
1. ESTADO - CATALOGO
================================================================================
@startuml Estado_Catalogo
title Estado - Catalogo
left to right direction

[*] --> PENDIENTE : proveedor envia propuesta

state "PENDIENTE" as PENDIENTE
state "APROBADA" as APROBADA
state "RECHAZADA" as RECHAZADA

PENDIENTE --> APROBADA : admin aprueba
PENDIENTE --> RECHAZADA : admin rechaza
APROBADA --> [*]
RECHAZADA --> [*]

---

[*] --> ACTIVO : alta aprobada

state "ACTIVO" as ACTIVO
state "INACTIVO" as INACTIVO

ACTIVO --> INACTIVO : admin desactiva
INACTIVO --> ACTIVO : admin reactiva
@enduml

5. NAVEGACION - CATALOGO
================================================================================
@startuml Navegacion_Catalogo
title Navegacion - Catalogo
left to right direction

component "Catalogo" as Cat
component "Detalle de producto" as Det
component "Vestidor AR" as Ves
component "Disponibilidad" as Dis
component "Carrito" as Carr

Cat --> Det : abrir prenda
Det --> Ves : probarsela
Det --> Dis : ver stock
Ves --> Det : volver
Dis --> Det : volver
Det --> Carr : agregar
@enduml
